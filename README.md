# Flight Coalition Formation

This project studies how to group travelers into coalitions to maximize the discounts obtained on flight tickets. It is modeled as a Coalition Structure Generation problem: find the partition of agents into coalitions that maximizes the total value (cumulated discounts).

Two approaches are implemented and compared:
- **IP** (Integer Programming): an integer linear programming formulation;
- **IDP** (Improved Dynamic Programming): an improved dynamic programming algorithm that reduces the number of operations compared to the classical version.
